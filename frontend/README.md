# Frontend — SmashConnect

Application frontend Vue 3 pour la plateforme SmashConnect.

## Stack

- Vue 3 (Composition API)
- Vite 7
- Pinia (state management)
- Vue Router 4
- PrimeVue 4
- Tailwind CSS 4
- Vitest (tests unitaires)
- Playwright (tests e2e)

## Installation

```bash
npm install
```

## Lancer en développement

```bash
npm run dev
```

Le frontend tourne sur `http://localhost:5173`.

## Build

```bash
npm run build
```

## Tests

```bash
# Tests unitaires
npm run test:unit

# Tests e2e
npm run test:e2e
```

## Linting

```bash
npm run lint
```
